# Portfolio assets

Assets are loaded from `public/` (copied from `Images_and_Videos/`):

- **game1.mp4** – DaGame (2D Platformer); used on About page background and project card/detail
- **game2.mp4** – Square Game (Momentum Platformer)
- **game3.mp4** – Rat Stranding (Stealth Puzzle)
- **ProfilePic.jpg** – Profile photo (navbar, footer, About page)
- **Resume_Praket_Aggarwal.pdf** – Resume (Resume page "Download PDF" button)

To refresh assets, copy updated files from `Images_and_Videos/` into `public/`.

## YouTube (optional)

In `src/data/projects.js`, for any project you can set `youtubeEmbedId` to the video ID to embed a YouTube video on the project detail page instead of a local file.
